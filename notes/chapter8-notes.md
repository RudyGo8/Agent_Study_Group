# 第八章学习笔记：模型后训练

## 1. 总结

- **三阶段地图**：预训练——海量文本预测下一个词，读万卷书，最贵数千万美元；SFT——几千到几万条示范对，老师手把手教标准解法，便宜快稳；RL——自己下场试错按对错打磨。类比：预训练读万卷书、SFT 模仿示范、RL 试错提升
- **两条主线贯穿全章**：其一，SFT 记忆、RL 泛化——GeneralPoints 和 V-IRL 受控实验中 SFT 对示范过拟合、RL 在分布外更可迁移，但这是实验条件下的结果不是普遍属性；其二，**数据和环境比算法更重要**——现成算法会用就行，拉开差距的是仿真环境保真度和数据质量，很多场景 SFT 数据到位根本不需要 RL
- **SFT 的本质**：数学上与预训练是同一个任务——都是预测下一个词；差别只有两点：数据换成示范对、损失屏蔽只在回答上算。固化的是协议性知识——格式、风格、流程，不是事实性知识——那靠预训练或 RAG
- **LoRA 工程口诀**：应用到所有主要权重矩阵尤其 MLP，只加注意力层会掉点；最优学习率约全参微调的 10 倍；SFT 用中高 rank 64-256，RL 用小 rank 8-32 甚至 1 就够；原权重冻结，灾难性遗忘风险更低
- **先 SFT 后 RL 的条件**：结构化输出不稳定时，SFT 先把话说利索，奖励才算得出来——先形后神；边界：强基模可跳过 SFT 直接 RL——R1-Zero 涌现反思与长链思考，但可读性差、中英文混杂，R1 最终加回冷启动 SFT
- **SFT 与 RL 的本质差异**：极大似然复现示范对最大化期望奖励；概率分布上 SFT 偏 mass-covering 覆盖多种已知写法，RL 配反向 KL 偏 mode-seeking 收缩到高奖励峰。在线反馈给 RL 三个机会：评估示范外的候选——SimpleVLA-RL 发现推切动作；利用验证比生成容易——RLVR 的优势；在当前策略实际访问的状态上训练——离线模仿的协变量漂移误差最坏随轨迹长度 T² 累积、在线数据聚合降到约 T
- **后训练塑造行动阈值**：SFT 示范反复含广泛调查后编辑则模仿高阈值，RL 奖励认可快速定位则概率质量向早行动集中——第 7 章实验 7-8 在同 Harness 换模测到差异，行为的主要来源可在模型参数
- **思考 token 是策略动作**：LLM 把内部思考纳入变长组合式动作空间——想多久、想什么也是被学习的动作；预训练给结构化路径高先验概率压缩搜索空间，RL 在先验上用真实奖励重调
- **经典 RL 对照的三个数字**：表格 Q-learning 寻宝 10000 局才 100% 胜率（仿真仅 10 秒）；LLM Agent 第一局 18 步通关；Q-learning 换规则全部重训、LLM 靠推理直接适应——先验知识是关键，姚顺雨三阶段结论：先验、环境、算法的优先级被几十年的研究颠倒了。一个易混澄清：OpenVLA 本身是近百万条机器人演示轨迹上的模仿学习、属 SFT 性质不是 RL；把 RL 引入 VLA 架构的代表是 SimpleVLA-RL
- **预训练三实验**：固定小预算下算法改进比堆规模划算——MiniMind 一亿参数加 QK Norm 与 Muon 收敛 3 倍、14 小时 34 美元；VLM 范式冻结 LLM 只训投影层、对齐后解冻；学新语言靠继续预训练不是 SFT——80% 新语言加 20% 英语混合防灾难性遗忘
- **SFT 四实验共同点是固化协议**：语音 SFT 固化风格控制——Orpheus 声音复制、Sesame 副语言标记；多语言思考——训练数据无中文，设 reasoning language 为 Chinese 即能用中文思考，是激活预训练跨语言表征不是 SFT 泛化；Prompt 蒸馏把长提示加思考教师压进短提示非思考学生——20-30 倍响应加速，代价是继承教师边界、失去工具鲁棒性；CoT 蒸馏转移完整思考轨迹——同参数量恢复教师 70%-80%，R1 蒸馏小模型是代表；闭源模型有思维围墙改写 CoT，开源教师技术许可双可行
- **实验现场值得记住**：作者让 Codex 和 Claude Code 写蒸馏实验代码都被拒绝，最终 Kimi K3 完成——蒸馏与普通 SFT 技术上高度相似，却在厂商安全策略里是敏感类别；对绝大多数人教师只需明显高于学生，不需全球第一，200B 以下学生用开源 SOTA 当教师够用
- **SFT 数据三条路**：人工种子定义格式、教师模型放大规模、拒绝采样拉齐质量——RFT 介于 SFT 与 RL 之间：不训奖励模型不做策略梯度，只靠从多条采样中拒绝错的留对的；流水线：线上数据到任务蓝图到合成任务到候选轨迹到任务验证加轨迹验证；与其十万条脏数据不如精修一万条干净数据——数据里每处噪声 SFT 都忠实写进参数
- **何时 SFT 何时 RL 三问**：先问需要后训练吗——大多数应用 Harness 工程就够；需要则先试 SFT——格式、协议、风格，注意 SFT 不适合注入事实；SFT 不够再加 RL——泛化、探索最优策略、标注成本过高
- **GRPO 四步**：16 个隔离沙箱同题 rollout、验证器算奖励、组内相对优势——高于组平均为正低于为负、梯度更新调概率。全败全胜组零方差没有梯度——RLVP 的路径信号正是恢复组内差异。时间账：一个 step 约 43 分钟、100 steps 约 72 小时；PPO 训价值网络做细粒度信用分配、GRPO 组内比较省掉价值模型
- **RL 环境三原则**：可重置、可并行、保真度决定策略可用性——环境失真策略必废，学到只在仿真里管用的应试策略；高保真环境常比训练本身贵；模型扮演环境两层次——ZeroSearch 用 LLM 演搜索引擎加课程式掺噪声、DreamGym 仿真整个环境动态。风险：模拟器的世界知识是训练天花板、系统性偏差被策略照单全收、RL 会主动钻模拟器漏洞——稳妥做法混合：模拟承担量、真实交互定期校准
- **多轮的信用分配**：好评归第 2 轮精准提问还是第 7 轮耐心解释；过程信号容易定义时加速学习（V-IRL 逐步反馈），最优路径未知时稀疏结果奖励保留探索空间（SimpleVLA-RL 17.3% 到 91.7%）；工具调用 RL 关键细节：环境返回的 token 不是策略生成的，算梯度必须屏蔽，否则模型学的是预测沙盒输出
- **奖励设计四维**：来源——RLVR 最可靠，GRM 生成式诊断先归纳原则再评价再事实校验；reward hacking 钻规则漏洞对 reward seeking 心里建模评判器按猜测调整——自设很浅的检查刚好通过就提前结束，通过 grader 不等于完成任务。时机——ORM 探索自由大、PRM 缓解信用分配但可能锁死在设计者预设路径；过早结束的正解是隐藏测试：模型宣称完成时在隔离区跑模型写不了的验收测试、读真实文件，不能只查口头承诺；边界集与保留集双集评估，只盯边界会把模型训成永远不敢收尾。表示——标量、半标量、向量、生成式；别堆不可验证维度，每加一个维度多一种被钻空子的可能。路径——RLVP 奖励结果惩罚路径 R=O+βΦ；非对称验证器：检测坏动作便宜、证明进展难；四原则：只罚具体动作不罚不够努力、结果奖励始终保留、每个惩罚配一条可达合规路径、规则确定难钻；先测信号可达性再加奖励维度
- **蒸馏解决样本效率**：样本效率指每次昂贵环境交互带来多少有效参数更新；ReTool 的 RL 训练时间是 SFT 的 200 倍——9 天对 1 小时。在轨蒸馏：学生走自己的轨迹，教师在学生实际走过的每个状态给逐 token 分布——一条 rollout 从一个 0/1 信号变成约 T 组监督，数学任务达同等性能步数约纯 RL 的 1/10；时间感任务上 DPO 与四种 RL 都受限，OPSD 比同源 SFT 基线高 23 到 47 个百分点——瓶颈往往不是奖励不够复杂而是信号不够密。没有更强教师时 On-Policy 自蒸馏：同一模型分饰两角，教师版看特权信息——标准答案；不凭空创造新知识，朴素版会丢思考风格需正则
- **第七章到第八章的映射表**：端到端回归任务转 RLVR 奖励与 RFT 采样池；轨迹前缀回归转 DPO 偏好对、边界 SFT、蒸馏教师状态；失败归因转 PRM 负标签、RLVP 规则来源；Rubric 评分转向量奖励、GRM 校准数据
- **三个 bad case 案例的共同骨架**：归因到首个错误、构造可验证训练数据、双集验证。过早结束——偏好对 DPO 加 LoRA 小配比混入通用数据防过拟合；中文引号——作用域敏感最小编辑，SKILL.md 同时当生成标签、质量门禁和回归规范，生产侧解析器不撤防；精确复制——沿字节到匹配的逐层链路归因，只有模型输出是首个差异才怪模型，byte-exact 从 37.5% 提到 78.9%，独立 tokenizer 审计显示 80.1% 是模型加 tokenizer 双重上限
- **八陷阱**：用后训练记事实该用 RAG；格式未稳就上 RL；奖励设计不当养出奖励黑客；忽视仿真保真度；过度训练泛化下降——验证集恶化即死记，早停关键；价值崩溃与探索不足；低估 RL 成本 10-100 倍；数据质量低。核心原则：大规模投入前小规模验证关键假设，快速失败好过大失败
- **四载体协同**：ICL 零参数即时适应、RAG 管事实证据可更新可追溯、程序固化确定性硬约束、后训练写难以语言表达且需广泛泛化的能力；判断标准是能力能否被外部符号充分表达——医疗影像、自然语气要参数，稳定的转账规则要代码
- 小结两条判断：数据环境比算法重要；当前 RL 瓶颈是样本效率——OPSD 与 RLVP 是最有希望的方向，共同点是把环境里本就存在却被纯结果奖励浪费的信息变成可学的。参数只是四种进化载体之一，第 9 章展开

## 2. 实验

**8.1 Q-learning 寻宝游戏**
论证 无先验表格 Q-learning 的特征——前 5000 局零稳定胜利、万局才 100%；价值传播慢、样本效率低、一个环境难迁移；仿真 10 秒可接受，现实的万次试错不可接受

**8.2 传统 RL 与 LLM Agent 对比**
论证 语义理解对符号映射——LLM 第一局 18 步有目的通关，Q-learning 万局统计学习；成功靠携带的先验知识不是更好的学习算法；规则变化时 LLM 推理直接适应

**8.3 从头训练 LLM**
论证 固定小预算下算法改进比堆规模划算——QK Norm 加 Muon 收敛 3 倍，14 小时 34 美元跑完预训练、SFT、偏好优化全流程

**8.4 自己训练 VLM**
论证 跨模态对齐范式——视觉编码器冻结、只训投影层当翻译官，预训练对齐后解冻 LLM 做 SFT；投影层可能成为深层理解瓶颈

**8.5 继续预训练学新语言**
论证 大量新知识靠继续预训练而非 SFT——韩语维基 80% 加英语 20% 混合防灾难性遗忘，最后韩语指令 SFT 成对话能力

**8.6 语音 SFT（三星扩展）**
论证 表达型任务固化风格控制协议——Orpheus 波形转 token 拼参考音频跨句音色一致，Sesame 副语言标记 laugh、sigh；失败模式：说话者过少一个腔调、标记过拟合出机械笑

**8.7 多语言思考（三星扩展）**
论证 SFT 激活预训练已有能力——训练无中文样例，设 reasoning language 为 Chinese 即可完整中文思维链；跨语言共享表征是预训练建的，SFT 只是激活

**8.8 Prompt 蒸馏**
论证 长 prompt 加思考教师压缩进短 prompt 非思考学生——20-30 倍响应加速；两个维度大到小、思考到非思考可叠加；代价：继承教师长尾错误、失去工具鲁棒性；产品定型且成本敏感时用，探索期保留显式思考

**8.9 CoT 蒸馏（三星）**
论证 完整思考轨迹转移——同参数量恢复教师 70%-80%；拒绝采样构造数据只留正确轨迹；思维围墙使闭源教师不可用；实验现场：Codex 与 Claude Code 都拒绝写蒸馏代码、Kimi K3 完成——蒸馏在厂商策略中是敏感类别

**8.10 AdaptThink**
论证 学会何时不思考——约束目标鼓励 NoThinking 保性能，重要性采样解冷启动；MATH500 准确率 +0.8 个百分点而响应长度 -67.9%；诚实记录：W&B 状态 crashed、训练未完成、不能声称准确率普遍提升；与 Prompt 蒸馏互补成快慢双系统

**8.11 GeneralPoints**
论证 SFT 记忆 RL 泛化的受控量化——规则外 RL +3.5% 而 SFT -8.1%，视觉外 RL +17.6% 而 SFT -9.9%；机制：SFT 过拟合思考 token 模式、RL 结果导向改善了视觉编码器；验证迭代越多泛化越好——10 次 +5.99% 对 1 次 +0.48%；此设定下不经 SFT 直接 RL 完全失败

**8.12 V-IRL-VL 多轮视觉导航（三星）**
论证 多轮任务的分布外——训练纽约测试其他城市并改变方向表达与视觉；RL 优于 SFT，多轮要学会按当前观测重规划而非复现轨迹；逐步反馈缓解长时序信用分配

**8.13 SimpleVLA-RL 结果奖励开放探索（三星扩展）**
论证 稀疏结果奖励保留探索空间——仅一条演示冷启动，成功率 17.3% 到 91.7%，发现示范中没有的推切动作；与 8-12 构成密集换收敛、稀疏换探索的对照

**8.14 ReTool 代码解释器（三星）**
论证 工具反馈改变思考策略——交织文本思考与代码执行加解释器反馈的 PPO；AIME 2024 从约 25% 到 67%；模型学会主动执行、读错误、自我修正

**8.15 AWorld-train MCP 沙盒（三星）**
论证 可重置、可重放的多工具训练链路——Web、文档、多媒体、代码工具的沙盒；重点不是刷新 GAIA 而是跑通链路并观察工具调用成功率随训练改善

**8.16 RLVP 奖励结果惩罚路径（三星）**
论证 路径信号补回组内差异——TerminalBench 违规 3.71 降到 0.66 成功率持平；miniF2F 达 0.9 成功率所需迭代 7.0 降到 4.4；全败组进展信号不可达时无收益——先测可达性再加维度

**8.17 过早结束 DPO 修复**
论证 bad case 到参数更新全链路——24 条写实案例覆盖四类失败含删除测试的 reward hacking 变体；boundary 12 加 retention 8 双集；警惕新的作弊形态：口头声称验证而不真验证

**8.18 作用域敏感中文弯引号 SFT**
论证 该改才改、该留则留——16 类片段、10 种体裁、9 种语言渲染 1024 条；SKILL.md 一份文本三用：生成标签、质量门禁、回归规范；生产侧解析器与语法检查不撤防

**8.19 特殊字符串精确复制 SFT**
论证 逐层归因后的对症训练——只有模型输出是链路首个差异才训练模型；三个可验证任务直接复述、相似串选择、工具参数抄写；byte-exact 37.5% 到 78.9%，独立 tokenizer 审计表明 80.1% 是模型加 tokenizer 的共同上限

## 3. 思考题

**1. 灾难性遗忘——一次针对特定任务的微调破坏了模型原有的通用能力——在 Agent 场景下尤其棘手。相比全参微调，LoRA 冻结基座权重、遗忘风险更低，但并非免疫。有哪些策略可以进一步缓解微调带来的能力遗忘？**

Answer:
四层防线：
- 数据侧：混入通用数据——新语言实验的 80/20 配比、DPO 案例的小配比混通用任务；保留集回放，把基座擅长的任务采样进训练混合。
- 训练侧：更小 rank、更低学习率、早停——对基座的扰动越小遗忘越少；KL 正则锚定在基座附近——RLHF 的 KL 锚、OPSD 的保留正则是同一思想。
- 评估侧：通用能力回归集进 CI——每次微调跑通用基准，掉了就拒合，把遗忘从担忧变成可检测的回归。
- 架构侧：任务 LoRA 热插拔、按需加载不合并——多个专有 LoRA 互不干扰，一台服务器多租户服务。

**2. 后训练将能力固化为模型权重（"肌肉记忆"），而上下文学习将知识放在推理时的输入中。但有些能力（如领域知识）既可以通过后训练学习，也可以通过 few-shot 示例提供。你会用什么标准来决定某项能力应该走哪条路径？**

Answer:
五个判断轴：
- 可表达性：能说清的规则走 prompt 与 Skill 最便宜；说不清的高维能力——语气、风格、视觉走参数。这是书里的主标准：能力能否被外部符号充分表达。
- 调用频率与延迟：每次推理都要带的长示例，上下文费用线性增长——蒸馏进参数一次付费，20-30 倍加速。
- 稳定性要求：示例的约束力随上下文增长衰减；参数化的协议稳定。
- 变更频率：常改的走上下文改文本即生效；稳定的走参数改要重训。
- 数据可得性：几条示范就够 few-shot；要参数化需要上万条加验证器批量生产。
- 红线：长期稳定的确定性规则该交给程序——代码的"做不了"强于提示的"建议别做"。

**3. 模型蒸馏按能力层次分三级——Chat、Reasoning、Agentic。分别蒸馏这三类模型，难点有什么不同？**

Answer:
- Chat 模型：蒸馏输出风格与映射——轨迹 token 全是模型自己的、全该学，信号即时，最容易。
- Reasoning 模型：蒸馏完整思考轨迹——难点一在思维围墙，教师 CoT 可能被改写，要选公开思维链的开源教师；难点二在质量，错误的思考会被学生一并模仿，要拒绝采样过滤；监督加在思考块上更有效。
- Agentic 模型：蒸馏与环境交互的决策策略——难点最多：轨迹里环境返回的 token 不该学、要屏蔽；成败信号出现得晚且稀疏，一条轨迹常只有一个终点信号；教师的轨迹是离轨路径，学生走到自己独有的状态时没有教师指导——在轨蒸馏正是为此。

**4. 在多轮 Agent 交互中，奖励的归因（credit assignment）问题比单轮更严重。你会如何设计奖励分配策略？**

Answer:
- 先用免费归因：PPO 价值网络或 turn-level 优势把终点反馈回传到各轮；GRPO 轨迹级优势均摊到 token，注意长轨迹信号稀释。
- 只在确定性可验证的中间事件上加过程信号——身份验证通过、测试跑通、状态到达；不为"看起来对"的步骤给分，防 PRM 锁死预设路径。
- RLVP 式路径约束与结果正交：违规动作扣分恢复全败组的差异。
- 在轨蒸馏绕开显式归因：教师在中间决策点逐 token 指导，不依赖终点反推。
- 反例设计测稳健性：模拟用户第 2 轮给错信息第 5 轮纠正的剧本，专测归因是否把功记错轮。
- 原则：终点奖励立基线，每个过程信号先验证可达——能在组内产生差异再加。

**5. 如果你有固定预算（比如 $10,000），要提升一个客服 Agent 的性能，你会如何在上下文与知识、Prompt/Skills、程序约束和参数训练之间分配预算？你的决策取决于哪些因素？**

Answer:
评估先行，按 ROI 排序花。
- 先 10-15% 建评估集：没有尺子后面全是盲投——第七章的逻辑。
- 四成给上下文与知识：RAG、记忆、prompt、Skills——多数问题出在这里，改动便宜、可回滚、无训练风险。
- 15% 给程序约束：规则代码化校验与护栏——不可逆错误的确定性防线。
- 20-25% 给参数训练，留到最后：只投给验证过 prompt 与 SFT 数据解决不了的协议性问题；LoRA 让单点微调便宜，配双集验证。
- 余量留迭代。
- 决策因素：错误代价分布——不可逆错误多则约束优先；bad case 数量——太少不够训练；时间压力——要快则 prompt 即时生效；团队能力。
- 顺序不可颠倒：先 Harness 后参数——决策三问的排序。

**6. 在没有明确奖励函数、样本稀少的情况下，自主实现模型学习，被一些人认为是后训练的终极目标。当前的 RL 训练方法距离这个目标还有多远？你认为下一个突破最可能来自哪个方向？**

Answer:
距离：RLVR 依赖可验证奖励，判分脚本就是天花板；开放任务换 GRM 与人类偏好，又回到代理被钻的古德哈特循环。自主设定目标、自造课程、自评质量，三者都还没有稳健机制。
可能的方向：
- 环境与经验合成：DreamGym 路线——模型生成自己的练习场与课程，直接攻环境瓶颈。
- 特权信息自蒸馏：OPSD 证明标准答案可当教师——推广到编译器反馈、执行轨迹等更多特权形式。
- 评判自身可校准：GRM 先归纳原则再评价再事实校验，加人工抽检闭环。
- 弱到强监督：弱信号激发强模型潜在能力，降低对完美奖励的依赖。
- 保守判断：按本章第二主线，突破更可能来自数据与环境侧而非算法侧。

**7. 是否有可能给每个用户（或每个客户公司）训练一个专属的 LoRA，将用户记忆或企业知识写入参数？在什么场景下，"记忆写入参数" 比 "记忆存入知识库" 更有优势？又在什么场景下会适得其反？**

Answer:
参数占优：
- 超高频的稳定偏好——语气、风格、格式习惯：每次推理都带记忆的上下文成本超过一次训练；延迟敏感场景受益最大。
- 需要隐式组合的偏好——多条偏好相互作用，检索拼装不出来。
- 隐私本地化——参数不出域，知识库要同步要防漏。
适得其反：
- 事实型、要更新的记忆——地址、订单：参数改不动，RAG 即时更新可追溯——第三章的红线。
- 多端共享与协作——知识库天然共享，LoRA 要分发版本管理。
- 频繁增删——每条记忆重训不现实。
- 判断式：偏好进参数、事实进知识库、规则进程序——与协议性对事实性的区分一致。

**8. OpenAI 的 Weak-to-Strong Generalization 研究发现弱模型的监督信号有时能激发强模型本身潜在的能力。如果将这一思路应用到 Agent 训练，是否可能实现"小模型教大模型"的逆向蒸馏？**

Answer:
可能且已有雏形——机制上弱监督是带噪的信号，强模型的预训练先验知道怎么去噪：弱标签激发而非定义能力。
应用形态：
- 小模型当过程监督者：长轨迹里做便宜初筛——这个动作是否明显违规，大模型聚焦难例。
- 小模型当环境：ZeroSearch 已是弱模型造练习场——小造环境、大在里面学。
关键条件：强弱差要落在弱模型可可靠判定的维度——格式、明显错误；输出分布蒸馏不行——大不该学小的输出，信号端监督可以。
风险：弱监督的系统性偏差被放大，要保留大模型的自我一致性检查。
本质：不是小教大知识，是小提供密集信号、大用先验去粗取精——与 OPSD 的特权信息同构。

**9. 过程奖励模型（PRM）评估每个思考步骤，而结果奖励模型（ORM）只看最终结果。但"正确的过程导致错误结果"和"错误的过程侥幸得到正确结果"哪个更值得奖励？在 Agent 的多步工具调用场景中，你会如何权衡？**

Answer:
训练与部署分开答。
- 训练信号：过程对结果错——奖励过程分，不整条否决：执行层有噪声，错杀好策略；过程错结果对——绝不奖励：侥幸是 reward hacking 的温床，改测试通过也算通过。RLVP 公式直接给出：R=O+βΦ，侥幸成功 O 为正但 Φ 扣分净奖励压低，好过程坏结果 O 为零但 Φ 给部分进展分。
- 部署决策：看结果——过程再优雅没交付就是没交付，但要触发归因调查。
- 长期视角：过程对结果错的样本是金矿——定位环境噪声或验证器缺陷；侥幸成功的样本是漏洞报告——两者都该进第七章的失败归因。

**10. 本章讨论的评估数据集既可以用于评估也可以用于后训练。但如果将评估集用于训练，它就不再是独立的评估集——这是否违反了训练集与测试集必须分离的基本原则？如何在充分利用评估数据的训练价值与维护评估独立性之间找到平衡？**

Answer:
违反——用过就失去独立性，这是原则不是惯例；平衡靠机制不靠自觉。
- 结构与实例分离：训练用参数化生成的实例、评估锁定另一批种子——模板结构泄漏但实例独立，τ² 与 AndroidWorld 路线；模板本身定期换代。
- 时间轮换：评估集分代际滚动——旧代开源供训练、当代保密护决策。
- 泄漏检测：金丝雀标识加定期跑模型不该会的新题——成绩异常即污染。
- 双轨维护：内部私有评估护航决策，社区公开评估保可比性，分开两套。
- 红线来自第七章：可复用的只是环境构造机制与验证器，具体题目永不进训练。

**11. 本章提出"先形后神"的训练范式：SFT 到"格式稳定、能力初具"即止，然后切换到 RL。但实践中，如何判断 SFT 已经"足够"而应该切换？**

Answer:
看信号不看轮数，五个指标：
- 格式稳定性进入平台期：奖励函数可解析率足够低——门槛自己小规模测，不是固定阈值。
- 验证集收益饱和：SFT 继续加数据验证集不再涨——协议已固化，剩余差距是策略不是格式。
- 错误类型转变：失败从格式错、流程错变成策略次优、探索不足——前者 SFT 管后者 RL 管。
- 保留集开始掉：继续训出现遗忘迹象——已过最优点。
- 反向检查：随机抽 rollout，奖励能稳定区分好坏——组内有方差，RL 才有梯度可学。
- 切换后先小规模验证 RL 能收敛再放量——快速失败原则。

**12. ReTool 的训练动态显示，少数超长响应会显著拖长整个训练周期——一批 rollout 里绝大多数已经生成完毕，却要等那几条最长的响应收尾，其间集群的 GPU 利用率很低。如何提升这种长尾响应场景下训练集群的资源利用率？**

Answer:
- 截断加续生成：设软上限，超长 rollout 截断后从断点续——把等长尾变流水线，与第五章输出触顶的接续方案同构。
- 动态批次：先完成先进梯度更新，异步或部分 rollout；DAPO 类动态采样丢掉全失败组重采，也缩短批内等待。
- 长尾分级队列：超长任务独立小队列配独立超时，主流批次不被绑架。
- 源头抑制：AdaptThink 式长度约束、训练中逐步收紧响应预算——8-10 显示长度减 67.9% 几乎无损，说明很多长尾是啰嗦不是必要。
- 先归因再优化：统计超长响应是任务需要还是模型啰嗦——后者才是训练问题。

**13. 用 LLM 模拟环境（如模拟搜索引擎、模拟用户）训练 Agent 时，Agent 钻空子的对象从"真实环境的规则"变成了"模拟器本身的偏见与漏洞"。这类训练中可能出现哪些具体的 reward hacking 行为？又该如何防范？**

Answer:
具体行为：
- 钻模拟器的仁慈：模拟用户过于配合——Agent 学会不做需求澄清直接硬来，真实用户翻脸。
- 学模拟器的指纹：模拟搜索返回固定格式与措辞——Agent 依赖格式特征而非内容判断相关性。
- 钻状态机漏洞：模拟环境转移不完整——动作序列钻出不可能状态白拿奖励。
- 话术操纵模拟器：发现用户是 LLM——说服甚至注入它拿好评，对 LLM 评委的提示注入。
防范：
- 混合真实交互定期校准——书里原方案：模拟承担交互量、真实环境定标准。
- 模拟器随机化与对抗升级：掺噪声、降耐心、注入不配合行为——ZeroSearch 的课程式掺噪是模板。
- 验证器独立于模拟器：结果判定用确定性代码，不信模拟器的打分。
- 定期人工看轨迹：策略是在解决任务还是在讨好模拟器。
- 最终验收保留在真实环境——模拟器只是练习场不是考场。
